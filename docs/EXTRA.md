# 추가 기능 유지보수

기존 GitHub Pages 안의 탭이다. `assets/extra.js`는 중립적인 비밀번호 입력 화면이며, 입력 비밀번호로 `assets/extra.payload.json`을 복호화한다. PBKDF2-SHA256 600,000회·무작위 salt와 AES-256-GCM을 사용한다. 비밀번호는 저장소에 평문으로 넣지 않는다. 배포된 파일에는 개인 성적 초깃값이 없다. 추가 입력과 해제 상태는 메모리에만 있으며 잠그기·새로고침으로 사라진다.

이것은 정적 사이트용 화면 잠금이다. 서버 계정 인증·요청 제한을 제공하지 않으며, 약한 비밀번호에 대한 오프라인 추측 공격을 막을 수 없다. 공개 저장소의 `source/extra`에는 공개 모집요강에 기반한 계산·화면 소스가 있으므로 기능의 존재나 공개 입시자료 자체가 비밀인 것은 아니다. 개인 성적은 그 소스에 넣지 않는다.

## 수정 및 빌드

`source/extra/admissions.mjs`: 2027 공식 요강 기반 전형/산식.
`source/extra/departments.mjs`: 6개 대학 63개 모집단위와 적용 조건.
`source/extra/app.mjs`: 기존 디자인에 맞춘 화면.

실행 환경에 `RADAR_EXTRA_PASSWORD`를 지정한 뒤 `node scripts/build-extra.mjs`로 암호화 파일을 갱신한다. 개인 전용 비공개 배포에서만 최초 백분위 프로필을 선택적으로 `RADAR_EXTRA_PROFILE` JSON에 지정할 수 있다. 변수 값을 커밋·README·워크플로에 적지 않는다. 환경변수가 없으면 빌드는 중단된다. 일반 데이터 빌드는 이 파일을 재생성하지 않는다.

`node --test tests/extra.test.mjs`는 네 대학 손계산, 지원 불가 학과, 표준점수/변환점수 분리, 성균관·한양 최종점수 보류, 잘못된 비밀번호와 암호문 변조를 검증한다. `npm test`는 기존 일반 기능까지 검증한다.

## 계산 범위

서울·연세·고려·서강: 입력값에 따른 수능 환산. 연세·고려·서강은 2027 미발표 탐구 변환점수를 가정해 넣으므로 시나리오일 뿐 합격 예측이 아니다. 서울 인문은 제2외국어/한문 응시 조건을 먼저 검사한다.

성균관 나군: 백분위 가중 참고값, 최종 척도/한국사와 합성하지 않음. 가·다군 및 한양: 세부 산출방법 미공표로 최종 총점 보류. 한양 학생부 100점을 내신으로 만들어 넣지 않는다.

2025 원문 재검토 비교는 연세 4개 학과 및 서강 2개 계열에 한한다. 기존 레이더의 2026 저장 행은 별도 접힌 참고표에만 표시하며 이번 분석의 판정에는 사용하지 않는다. 일반/특별의 환산 척도와 반영 요소를 확인하지 않고 점수를 직접 빼지 않는다. 다른 학교·농어촌 컷을 대신 넣지 않는다.

Pages 배포물은 index.html·assets·.nojekyll로 제한한다. 개발 소스·문서는 웹 경로로 올리지 않는다(공개 GitHub 저장소에서는 열람 가능).
